### Модуль безопасности (Security)

Модуль безопасности для защиты веб-службы от несанкционированного доступа, DDoS-атак и простых веб-уязвимостей. Реализует чтение настроек из трёх источников с явным приоритетом, раннюю валидацию конфигурации и два режима работы.

Использованный стек технологий: Node.js, Express

## Архитектура модуля Security

Модуль построен на **модульной архитектуре** проекта и интегрируется в общий конвейер обработки запросов. Модуль:

- Загружает конфигурацию из файла, переменных окружения и аргументов командной строки
- Выполняет раннюю валидацию всех настроек до запуска сервера
- Регистрирует middleware безопасности в DI контейнер
- Добавляет защитные заголовки к каждому ответу
- Ограничивает частоту запросов от одного источника

## Приоритет источников конфигурации

Настройки загружаются с явным приоритетом (от высшего к низшему):

1. **Аргументы командной строки** — наивысший приоритет
2. **Переменные окружения** — средний приоритет
3. **Файл конфигурации** (`config/security.json`) — низший приоритет
4. **Значения по умолчанию** — если ничего не задано

### Примеры запуска с разными источниками:

```
# Из файла конфигурации
node src/app.js

# С переменными окружения (PowerShell)
$env:SECURITY_MODE="боевой"; node src/app.js

# С аргументами командной строки (наивысший приоритет)
node src/app.js --security-mode=боевой --read-limit=100 --write-limit=30
```

## Конвейер обработки запросов (дополнение)
При включенном модуле Security каждый HTTP запрос проходит дополнительную обработку:

1. **RequestIdMiddleware** — добавляет уникальный идентификатор

2. **RequestLoggerMiddleware** — измеряет время выполнения и логирует

3. **SecurityMiddleware** — защита запроса:

* Установка защитных заголовков

* Проверка CORS (только доверенные источники)

* Проверка частоты запросов (rate limiting)

4. Маршрутизация — обработка запроса модулем

5. **ErrorHandlerMiddleware** — перехват и форматирование ошибок

## Установка и запуск
1. Клонировать репозиторий:
```
git clone https://github.com/Alx1307/study-tasks-modules.git
cd study-tasks-modules
```
2. Установить зависимости:
```
npm install
```
3. Запустить сервер в учебном режиме:
```
npm start
```
4. Запустить сервер в боевом режиме:
```
node src/app.js --security-mode=боевой
```
5. Запустить тесты безопасности:
```
npm run test:security
```
6. Запустить нагрузочное тестирование:
```
npm run test:load
```
Сервер запустится на http://localhost:3000
